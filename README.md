# Random-Walk-Simulation

**Description:** A client-server application simulating random movement in a 2D environment with optional obstacles. Demonstrates multithreading, multiprocessing, inter-process communication (IPC), and socket programming.

**Technologies:** C, Python (Pygame), TCP/IP, POSIX Threads

**Year:** 2026

**Course:** Operating Systems Principles (POS)

**Author:** Anna Bačinská

## How to Run

1. Compile the project using `make`.
2. Start the server: `./bin/server <port>`
3. Launch the graphical client: `python3 -m gui.app`

## Features

- Configurable 2D random walk simulation
- Interactive and statistical visualization
- Multiple client connections
- Saving and resuming simulations
